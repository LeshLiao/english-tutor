英文練習系統架構圖

依《英文學習 MCP Server 規劃》與《本機架設規劃》整理。左半是 Claude Code 這一側，負責判斷句子對錯；右半是 Docker 容器，只負責儲存與查詢。

兩條觸發路徑

  • Skill（手動）：你主動請 Claude 檢查一句英文。Claude 先呼叫 list_error_types 沿用現有分類，再呼叫 save_sentence 儲存，最後回覆修正句與說明。
  • Hook（自動）：每次送出 prompt 時，check_english.py 過濾掉程式碼與中文，只有真正的英文句子才在背景以 claude -p 另開一個 agent 分析，有錯誤才透過 MCP 儲存，主對話完全不受影響。
